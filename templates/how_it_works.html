THE LONG GAME

Where This Is Headed

Taken together, this is a system designed to never stop researching, to build a durable and cross-referenced model of the world and of itself, and to notice when its own reasoning is off and correct it — rather than a chatbot that only exists in the moment you're talking to it.

The path to more real-world agency is intentionally gradual and gated: code execution starts fully sandboxed, with each step toward broader autonomy (approval queues, then eventually real-machine access) requiring a deliberate decision from you first, not a quiet default. That's a design choice, not a limitation still waiting to be lifted.

This page is kept honest on purpose: NEX periodically reviews its own recent code changes and proposes updates to the cards above when something's gone stale, but nothing here changes without you approving it first — see "Pending Update Proposals" above when there's something to review.
